# DSH Remote 移动端视觉走查清单（真机 QA）

> 目的：Web 截图只能验证布局顺序，深色观感、字体、触控、动效必须在真机确认。
> 使用方法：连上电脑端 DSH 后，逐页走一遍，按项打勾；发现问题的直接截图反馈。

## 0. 全局

- [ ] 浅色模式下，阅读画布页面（对话/轨迹/设置/审批/插件）底色为暖白 `#F7F8FA`，不是纯白刺眼
- [ ] 深色模式下（设置→显示→深色），阅读画布为近黑，文字对比清晰
- [ ] 品牌画布页面（会话首页/引导/扫码）无论浅色/深色都是深蓝底，状态栏文字为白色
- [ ] 所有可点区域 ≥ 44pt，没有误触
- [ ] 页面左右留白 20，卡片圆角 15，无拥挤/贴边
- [ ] 紫色/橙色只出现在轨迹时间线和思考等级胶囊，其他地方没有

## 1. 连接首页 `/`

- [ ] 品牌锁 deepseek + HARNESS 清晰，鲸鱼无变形
- [ ] 深蓝品牌卡内：点阵鲸鱼、标题「探索未至之境」、副标题层级正确
- [ ] 扫码连接按钮为官方蓝 `#3964FE`，按下有缩放反馈
- [ ] 手动输入展开后：输入框白底 + hairline，聚焦时蓝描边
- [ ] 连接失败时红色错误提示在按钮下方，可重试
- [ ] 版本号在底部且弱化

## 2. 会话首页 `/sessions`（在线）

- [ ] 深蓝背景 + 技术网格 + 鲸鱼点阵，不刺眼
- [ ] 工作区卡：线条文件夹图标、工作区名、路径、状态点、下拉箭头
- [ ] 点工作区卡 → 底部 Sheet 列出「全部工作区」+ 各工作区，可筛选
- [ ] 「＋ 新会话」按钮点击后进入新会话
- [ ] 会话行：状态点（运行中绿/普通白）、标题、session-id 前缀、相对时间，行间有细分隔线
- [ ] 运行中的会话行显示绿色光晕点 +「运行中」
- [ ] 长按会话 → 底部 Sheet：重命名/派生/归档
- [ ] 下拉刷新正常，骨架屏为深色半透明条

## 3. 对话页 `/chat/[sessionId]`（在线）

- [ ] 顶部导航栏：会话标题 + 右侧状态点 + ⋯ 菜单

- [ ] 分段控件：对话白底选中、轨迹灰底，左右滑动可切页
- [ ] 消息气泡：用户蓝底白字、助手白底 hairline，代码块 mono 字体
- [ ] 流式输出时消息尾部有闪烁光标
- [ ] composer 上方统计 pill：`N 轮 · N 步`，点击切到轨迹
