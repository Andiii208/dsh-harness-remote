# dsh-remote UI 设计系统（v2）

产品显示名：**harness remote**。本规范 v2 的目标：把 v1 的「终端质感」从 token 落到
**可执行的设计语言**——排版层级、间距节奏、状态表达、空/载态、动效纪律，并明确
「什么样子算 harness remote、什么样子算 AI 模板味」。所有屏幕（v2 起）必须遵循本规范。

## 2. 排版（层级即信息）

- **显示标题**（仅连接页/引导页首屏用）：系统无衬线 26/700，letterSpacing -0.3。
- **页标题**：20/650，letterSpacing -0.2。页面标题永远左对齐，不居中。
- **区块标题**：15/600。
- **正文**：14/400，行高 20。
- **辅助文本**：12/400（muted / dim）。
- **mono 眉标（eyebrow）**：等宽 11/700，全大写，letterSpacing 1.4——用于区块标签
  （如 `SESSIONS`、`TARGET 192.168.1.5:3080`）、状态行、时间戳。这是本产品最
  有辨识度的排版元素：**数据以等宽呈现，叙述以无衬线呈现**。
- **mono 数据**：等宽 13/400（会话转录、token 用量、主机地址、错误码）。
- 禁止：衬线大标题、手写体、全大写正文堆叠、装饰性 emoji、霓虹渐变文字。

## 3. 组件规范

### 3.1 状态表达（色点 + 文本，不滥用徽章）
- `StatusChip`：8px 色点 + 等宽 11 文本（如 `● ONLINE` / `● CONNECTING` /
  `● BACKOFF 3.2s` / `○ OFFLINE`）。底 `surface`，描边 `border`，胶囊。
- 状态色只做「点 + 首字符」强调，不用大面积底色块。

### 3.2 卡片
- 底 `surface`、描边 `border` 1px、圆角 12、内边距 14。
- 需要承载「事件性质」时用左侧 3px 边条：warn=待审批 / accent=提问 / success=完成。
- 卡片之间间距 8–12；同屏卡片 ≥3 张时归入同一间距节奏（8），区块之间 24。

### 3.3 列表行
- 行高 60，内边距 14，底 `surface`，行间 8。
- 主行：标题 15/600 + 预览（muted 12，单行省略）。
- 元信息行：mono 11（工作区 / token 用量 / 时间），右对齐时用 `textDim`。
- 投影缩略（goal 进度 / context 压力）统一 3px 高圆角条，放行尾或行内尾部。
- 选中/按压态：`surface2` 过渡 140ms；不做整行描边变化。

### 3.4 按钮
- Primary：高 46、底 `accent`、文字 15/600 白、圆角 10；pressed 底 `accentHover`。
- Ghost：底 `surface2`、描边 `border`、文字 14/600 `text`。
- Danger-ghost：同 ghost，文字 `danger`。
- 禁用：opacity 0.4，不换色。
- 全宽按钮行距 12；两个按钮并排时 1:1，主操作在右。

### 3.5 输入
- 底 `surface2`、描边 `border` 1px、圆角 10、高 ≥46、内边距 12/14。
- 聚焦：描边 `accent` + 外环 `accentSoft`（宽 3，不透明度渐变）。
- 主机/端口/token 输入用等宽 13；占位文本 `textDim`。
- 标签（可选）用 mono 眉标 11 置于输入上方。

### 3.6 空态 / 错误态
- 空态：mono 眉标一行（如 `NO SESSIONS`）+ 正文一句 + 主操作按钮；居中但克制。
  禁止「欢迎！」式抒情；禁止插画。
- 错误态：`text` 一句人话 + mono 错误码（`NOT_FOUND` 等）+ 重试按钮。
  不展示堆栈；离线态优先给「重连」而不是「重试」。

### 3.7 加载态
- 列表首载：2–3 行骨架条（surface2 底、140ms 透明度脉动、圆角 6），不转圈。
- 连接中：状态点 `warn` + `CONNECTING` + 行内 progress（3px、accent、不定长）。
- 禁止：无限旋转 loading、闪烁霓虹、进度百分比抖动。

### 3.8 鲸鱼标记（WhaleMark）
- 32–40px 白色圆角方 + 黑色鲸鱼（复用 `apps/mobile/assets/icon.png`，
  圆角 10、白底裁切），仅出现在连接页与引导页品牌位。其余页面不重复放。

## 4. 屏幕布局

- **连接页（品牌 + 操作合一）**：顶部 WhaleMark + 显示标题 `harness remote` +
  mono 眉标 `DEEPSEEK HARNESS · LAN REMOTE`；中部状态行 + 「最近主机」列表
  （如有）+ 手动输入卡片（host / port / token）；主操作（连接 / 断开）固定底部安全区；
  安全提示用 `warn` 小字块；版本号 mono 沉底。
- **会话列表**：页标题 `Sessions` + `SESSIONS n` 眉标 + 状态 chip；待处理横幅
  （warn 边条 + 等宽计数）置顶；列表行如 3.3；空态如 3.6。
- **聊天页**：顶部会话标题栏（sticky，bg 半透明）+ 状态点；转录区 mono 13 流式；
  角色用 3px 边条 + mono role 标签，不用圆角气泡堆砌；输入条：输入框 + 发送按钮，
  离线时输入框禁用并显示 `OFFLINE` 眉标。
- **审批/提问页**：单卡居中（全屏），左侧边条按 3.2；命令块 `surface3` + mono。
- **设置页（v2 新增）**：分组列表（连接 / 通知 / 关于），行 = 标签 + 值/开关；
  版本信息 mono 沉底。

## 5. 动效（克制且一致）

- 状态颜色切换：140ms ease-out。
- 列表项入场：200ms fade + 6px 上移，逐项错开 24ms（≤6 项）。
- 按压反馈：140ms `surface2` / `accentHover` 过渡。
- 尊重系统「减弱动态」：`AccessibilityInfo.isReduceMotionEnabled()` 为真时跳过入场动画。
- 禁止：弹性回弹、3D 翻转、粒子、无限旋转、背景自动漂移。

## 6. 反模式（AI 味红线）

- ❌ 彩虹渐变 / 霓虹辉光 / 毛玻璃 / 玻璃卡片堆叠
- ❌ 通用插画、机器人脸、星星、emoji 图标、3D 鲸鱼渲染
- ❌ 全大写正文、居中大段抒情、每屏「欢迎！」
- ❌ 为装饰而加的编号（01/02/03）——序号只在真正是序列时使用
- ❌ 无意义的渐变背景、圆角 0 的「极简」与圆角 24 的「友好」两头摇摆
- ✅ 一切以信息与操作为先：等宽数据、无衬线叙述、单一强调色、克制动效
