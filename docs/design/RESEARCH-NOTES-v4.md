# UI 设计调研笔记（2026-08-17，v4 依据）

> 来源：两轮子代理调研（web_search/read_page 桥接器当时有 bug，代理改用 `npx @liustack/modsearch` CLI 完成检索）。
> 用途：v4 设计决策的出处与可核对数据。

## A. 终端/工具类产品美学（Warp / Linear / Raycast / Arc / Ghostty / Hyper / iTerm2）

### A.1 逐作品特征

- **Warp**：不是死黑，渐变背景 + 光晕；卡片半透明 + 背板模糊；边缘有细光（内发光、顶缘高光）；字体层次：几何无衬线标题 + 等宽数据；强调色用在「光」上。
- **Linear**：canvas `#010102`，页底 `#08090A`（带蓝调，从不用纯黑）；surface `#0F1011`→`#1C1C1F`（4 级亮度阶梯）；text `#F7F8F8`；muted `#8A8F98`；border `#23252A`；主色靛蓝 `#5E6AD2`，hover `#828FFF`；成功 `#27A644`。
  - 三特征：**无投影层级**（1px 发丝线 + 逐级变亮表面）；**单一彩色强调**（靛蓝只出现在「有意义的像素」）；**字体层级而非字重**（Inter Variable，标题 500–510 字重刻意不用 600/700，大标题 tracking −3px）。
- **Raycast**（与「远程控制命令工具」最接近的近亲）：`#07080a` 蓝冷底色、`#0d0d0d→#121212` 表面阶梯、`#242728` hairline、正字距 + 字重 500、珊瑚红 `#FF6363` 当标点。
- **Arc**：大胆品牌色、渐变、设计感强。
- **Ghostty/Hyper/iTerm2 精美主题**（Gruvbox/Tokyo Night/Catppuccin）：美在「色调叙事」——Tokyo Night 是蓝紫夜色、Catppuccin 是柔和奶昔色调，不是黑底白字。

### A.2 六条「为什么好看」的共性

1. 底色有主张（带色相，非死黑）
2. 亮度位阶 > 投影（层级靠更亮的表面 + 边线）
3. 光线有方向（顶部受光、边缘光、阴影下沉）
4. 字体分工（显示/正文/数据各司其职）
5. 动效有节奏（有意图的动作，不是到处乱动）
6. 质感三件套（渐变背景 + 半透明表面 + 顶部高光）

### A.3 「氛围感」五手法

1. 背景渐变（深蓝黑到黑的微妙渐变）
2. 光晕/光柱（径向渐变、方向性光）
3. 半透明材质（毛玻璃）
4. 微噪点/纹理（消除矢量感）
5. 一个「签名时刻」（整个界面只有一个让人记住的东西）

## B. 浅色/深色双主题精致设计（Linear / Notion / Bear / Things 3 / Figma / Tailscale + Apple HIG / Material 3）

### B.1 精确色值

- **Material 3**：深色 surface=tone6 `#1C1B1F`，surfaceContainerHighest `#36343B`；M2 深色 surface `#121212`，error 深色 `#CF6679`（浅色 `#B00020` 提亮 40% 白）；品牌深色 surface `#1F1B24` = `#121212`+8% 主色。
- **iOS**：bg `#000000`，secondary `#1C1C1E`，tertiary `#2C2C2E`；label 全同色相 `#EBEBF5` 不同 alpha（100/60/30/18%）；系统蓝 `#0A84FF`/绿 `#30D158`/红 `#FF453A`/黄 `#FFD60A`；浅色 secondarySystemBackground `#F2F2F7`。
- **Notion**：深色 bg `#191919`、侧栏 `#202020`、hover `#2F2F2F`、text `#E6E6E6`、强调蓝 `#2383E2`（浅色 `#487CA5`）。**状态色双套值**（最值得直接抄）：

| 状态 | 浅色 文字/底 | 深色 文字/底 |
|---|---|---|
| 红 | `#C4554D` / `#FAECEC` | `#BE524B` / `#332523` |
| 橙 | `#CC782F` / `#F8ECDF` | `#CB7B37` / `#36291F` |
| 蓝 | `#487CA5` / `#E9F3F7` | `#447ACB` / `#1F282D` |
| 绿 | `#548164` / `#EEF3ED` | `#4F9768` / `#242B26` |

- **Bear**：浅色侧栏 `#F7F7F7`、编辑器/列表 `#FFFFFF`、text `#333333`（软黑非 #000）、红 `#D14C3E`、代码块底 `#F5F5F5`；深色内置 Dracula/Nord/东京之夜/OLED 真黑 12+ 套主题（证明「深色要带色相/氛围」被用户用脚投票验证）。
- **Figma**：浅色画布 `#F5F5F5`（非纯白降反射）、深色 `#1E1E1E`（非纯黑）。
- **Tailscale**（官方博客《Heart of dark mode》）：深色加 `gray-1000`（更深）、悬浮面加边框、阴影不透明度 ×2、遮罩 ×10；**disabled 用透明度**（深色里「更浅=更可用」直觉反了）；**切主题禁用 CSS transition** 防颜色慢淡；`<meta name="color-scheme">` + 首屏内联脚本读偏好防白闪（FOUC）；语义化 token 一处定义两处生效。

### B.2 精致感共性

- **浅色**：非纯白底（3–5% 冷灰）；2–3 层表面阶梯（`#F2F2F7→#FFFFFF`）；软黑正文（`#333`/`#373530`）；1px 低对比发丝线；柔和多层阴影（小偏移低透明度）；字号+字重+tracking 三级；玻璃/半透明透品牌色。
- **深色**：带色相的黑（蓝/紫/绿调）；真黑仅 OLED 场景；层级用「更亮的表面」（反向于浅色的阴影）；边线替代阴影；文字近白 `#E0E0E0~#F0F0F0` 非纯白；强调色提亮+提饱和（深色里浅色强调色会「洗白」）；降饱和用色（深色高饱和会「振动」，降约 20 点）；状态色双套值。

### B.3 双主题翻车清单

1. 深色正文纯白过曝 → `#E0E0E0~#F0F0F0`；M2 悬浮面白字 ≥15.8:1、正文 ≥4.5:1
2. 状态色不能「反转/复用」，红绿蓝深色需单独一套
3. transparent PNG 图标浅色里会消失；插画需「夜间版」
4. 深色阴影 10% 透明度=没有 → 加不透明度或改亮边+亮面
5. disabled 用透明度统一表达
6. 禁止散落 `dark:` 类，必须语义 token
7. 切主题禁 transition、加 color-scheme meta、首屏内联读偏好
8. 品牌色深色需要提亮变体

### B.4 规范要点

- **Apple HIG**：base/elevated 双背景（base 更暗退后、elevated 更亮前移）；深度靠颜色不靠阴影；label 四级文字同色相不同 alpha；优先系统材质/颜色。
- **Material 3**：M2 surface `#121212`，elevation 用 on-surface 半透明叠层（4dp 8%、8dp 12%）；M3 改 tonal elevation（主色 tint 叠层）；深色强调用更亮更低饱和的 tone，避免饱和色在暗底「振动」。

## C. 结论 → v4 采纳

1. 深色 canvas 带蓝调渐变（Linear/Raycast 蓝冷底 + Warp 渐变氛围）
2. 卡片半透明 + blur + 顶部 1px 高光（软玻璃拟态，Things 3/iOS 材质）
3. 强调色双套（浅 `#3D5AFE` / 深提亮 `#6E8BFF`）；状态色双套（Notion 规律）
4. 显示字体 Space Grotesk（告别系统默认），数据 JetBrains Mono
5. 鲸鱼 = 品牌签名时刻（深海叙事 + 呼吸动效），不做贴纸
6. 动效克制 + 尊重减弱动态（Apple HIG）
7. disabled 用 opacity；切主题禁 transition 防白闪（Tailscale）

## D. 第二份调研（开发者工具美学，Warp/Linear/Raycast/Arc/Ghostty/Hyper + 终端主题）

### D.1 可执行 token（迁移价值最高的几条）

- **Warp**：16 ANSI 色 + 单一 accent 做地基；「UI surface = 主题底色 + 相反色 overlay + 描边」分层法；命令+输出分组为 **block**；默认字体 Hack、强制最小对比度。
- **Linear**：底色 `#08090a`；Inter 非常规字重 **510/590**（不用 600/700）；标题负字距 −0.04em；间距 4px 基准；**圆角两极**（小元素 2–6px、主 CTA **160px 药丸**）；阴影用 **inset 内嵌**而非黑色投影；品牌去饱和靛蓝 `#5e6ad2` + 产品 CTA 电钴蓝 `#3b63f7` + Ion Teal `#2ab5b5`；招牌渐变 = 角度渐变 + layer blur（aurora mesh）。
- **Raycast**（迁移价值最高）：底色 `#07080a` 蓝冷近黑（**明确禁纯黑**）；表面 `#0d0d0d→#101111→#121212→#18191a` 每级差 1–2 阶；hairline `#242728`；键盘键帽**内阴影**（卡片「按进去」非「浮起来」）；**正字距 +0.2~0.4px + body 字重 500**（反直觉：深色 UI 更透气）；Inter(ss03)+GeistMono；单一珊瑚红 accent `#FF6363` 占 2% 当标点；玻璃导航 blur 48px + 1px `#363739`。
- **Arc**：SF Pro + 半透明表面 + 渐变暖意；暗底 letter-spacing 4%。
- **Hyper**：Dracula 系 16 色（red `#ff5555`/green `#50fa7b`/blue `#bd93f9`/magenta `#ff79c6`/cyan `#8be9fd`）。
- **终端主题硬数据**：Tokyo Night `#1a1b26`/`#a9b1d6`（9.5:1 霓虹电影感）、Catppuccin Mocha `#1e1e2e`/`#cdd6f4`（12.1:1）、Gruvbox `#282828`/`#ebdbb2`（暖）、Nord `#2e3440`/`#d8dee9`（冷）。

### D.2 六共性（与 A.2 互证）

1. 底色有主张绝不用纯黑（近黑带 1–3% 色相偏移）
2. 纵深靠亮度位阶 + 内嵌描边/内发光，不靠黑色投影
3. **光线有固定方向**（左上亮→右下暗，边框一侧近白一侧浅灰模拟反光）
4. 无衬线 + 等宽 accent，字距方向统一且刻意
5. 动效节奏一致克制物理化（同一 easing/timing 复用）
6. 质感三件套 = 毛玻璃(blur+渐变描边) + 噪点 + 内发光

### D.3 氛围感五手法（与 A.3 互证）

1. 底色加色相温度永不 `#000`
2. 用光而非边框做层次（固定方向光晕 + 内嵌高光描边）
3. 单一 accent 当标点（占 2%）
4. 玻璃 + 噪点 + 内发光中和塑料感
5. 字距字重做反直觉但统一的决策（正字距 500 或负字距超紧）+ 等宽字体建身份

### D.4 三屏迁移建议（v4 可继续吸收的点）

- **连接页**：蓝冷近黑 + 左上 radial 光晕（呼吸「主机在线」感）+ 玻璃卡片(blur 24px + 渐变描边 + 顶部 edge highlight)；状态用光表达（在线=呼吸光、连接中=琥珀、断开=灰）；**主 CTA 160px 药丸电钴蓝 `#3b63f7`**；辅助文字正字距 +0.2px、字重 500。
- **会话列表**：行 `#0d0d0d` + hairline `#242728` 分隔 + 选中 inset 1px `rgba(255,255,255,0.06)`；元数据等宽 tabular-nums mute `#9c9c9d`；「运行中」用唯一彩色；动效 stagger 进入 + 高度收起退出，同一 `cubic-bezier(0.4,0,0.2,1)`。
- **聊天页（Warp block 概念，最值得抄）**：把「聊天」当「终端 block」——**用户消息=命令块、AI 回复=stdout、工具调用=日志**；block 圆角分组 + 折叠 + 复制；代码高亮直接用 Tokyo Night/Catppuccin 16 色而非 VS Code 主题；流式输出用珊瑚块状光标闪烁；顶栏玻璃 blur + 等宽 host:port；输入区内凹槽 `#18191a` + 药丸发送。
